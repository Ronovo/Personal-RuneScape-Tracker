Your OSRS character log and GE tool, on your own server

Hiscores, quests, diaries, combat achievements and your collection log in one place, alongside Grand Exchange market views and a Flip Helper. You host it yourself, for just you or a group of friends.

What it does

One responsive app for keeping track of a character and the market, on desktop or phone.

Character

Look up any player's Jagex hiscores.

  • Combat level, total level and XP
  • Skill levels, XP and ranks
  • Boss kill counts and minigame scores

Progress from RuneLite

What the hiscores don't show, synced from the Leagues Tasks plugin.

  • Quests, with type and membership filters
  • Achievement diary tiers by area
  • Combat achievements and points
  • Collection log, obtained and missing
  • Completed Leagues tasks

Grand Exchange

Browse and filter OSRS Wiki market data.

  • 24-hour risers and fallers
  • Price, volume and freshness filters
  • Item pages with a price history chart, margins and alch values

Flip Helper

Scan the market for buy-low/sell-high opportunities.

  • After-tax profit, ROI, GP/hr and confidence
  • Presets, filters and a per-character watchlist
  • A calculator you can load any item into

Prices come from completed trades, not live offers. Always check the in-game GE offer box before committing money.

Plugin sync

Jagex doesn't publish quests, diaries, combat achievements or the collection log. Those tabs fill in when you sync from the RuneLite plugin, pointed at your tracker.

  1. Run the tracker (below) and copy your token with Copy plugin token in the header.
  2. In the plugin's Sync Settings, set Server URL to the tracker's base address (for example http://localhost:4123, or https:// for anything not on this computer) and paste the API Token.
  3. Log in to OSRS and press a Sync button. The collection log syncs from the Sync button on the in-game Collection Log.

Each sync only updates the sections it sends. Leaving a section out never clears what the tracker already has.

Run it

The tracker is a small Node server you host yourself. There is no shared public instance.

With Node

  1. Install Node.js 24 or newer.
  2. Get the source: on the GitHub page choose Code → Download ZIP and extract it, or clone the repository.
  3. In that folder, install and start it: 
    npm ci
npm start
  4. Open http://localhost:4123. Other devices on your network can use http://<computer-address>:4123.

With Docker

docker build -t osrs-tracker .
docker run -d --name osrs-tracker --restart unless-stopped \
  -p 4123:4123 \
  -e JWT_SECRET=a-long-random-secret -e LAN_MODE=1 \
  -v osrs-tracker-data:/app/data \
  osrs-tracker

Keep the -v volume: it holds every synced character and watchlist. Without it, that data is lost when the container is removed. docker logs osrs-tracker shows the LAN token.

Who can sync

SetupGood forHow tokens work
JWT_SECRET + LAN_MODE=1 You or friends on a home network One shared token, printed when the server starts
JWT_SECRET only A site on the internet (use HTTPS) Each player registers and copies a personal token
Neither Just hiscores and the GE Syncing is turned off

Never set LAN_MODE on a host reachable from the internet. Full setup, hardening options and the API are in the README.
